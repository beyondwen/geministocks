# Google OAuth 快速开始指南

## 5 分钟快速上手

### 步骤 1：确认环境变量已配置

```bash
# 环境变量已自动配置：
VITE_GOOGLE_CLIENT_ID=249907665019-71e2lkp4m8l9tf7cd6o45fuj2v08tash.apps.googleusercontent.com
```

### 步骤 2：启动开发服务器

```bash
npm install
npm run dev
```

应用将运行在 `http://localhost:5173`

### 步骤 3：打开登录页面

1. 打开浏览器访问应用
2. 点击右上角的登录按钮
3. 在弹出的登录框中，选择"使用 Google 账号注册"

### 步骤 4：使用 Google 账户登录

1. 点击 Google 蓝色按钮
2. 授权 Google 账户
3. 应该自动登录并回到应用
4. 你应该获得 15 积分

### 步骤 5：验证登录成功

- ✅ 右上角显示你的用户名
- ✅ 显示 15 积分
- ✅ 能进行分析操作
- ✅ 可以查看账户菜单

## 核心功能快速体验

### 1. 新用户首次登录

```
1. 点击"使用 Google 账号注册"
2. 授权 Google 账户
3. 系统自动创建账户
4. 获得 15 积分（10 基础 + 5 Google 奖励）
5. 自动数据同步
```

### 2. 现有用户登录

```
1. 点击"使用 Google 账号登录"
2. 授权 Google 账户（如已授权可直接登录）
3. 账户数据自动同步
4. 积分和历史数据恢复
```

### 3. 账户关联（可选）

如果已有邮箱账户，可以关联 Google 账户：

```
1. 登录你的邮箱账户
2. 进入账户设置
3. 点击"关联 Google 账户"
4. 授权你的 Google 账户
5. 之后两种方式都能登录同一账户
```

## 常见操作

### 如何退出登录？

1. 点击右上角用户头像
2. 选择"退出登录"
3. 将返回未登录状态

### 如何查看账户信息？

1. 点击右上角用户头像
2. 选择"账户设置"
3. 查看关联的 Google 账户

### 如何解绑 Google 账户？

1. 进入账户设置
2. 找到 Google 账户部分
3. 点击"解绑"（需要已设置密码）

## 可能遇到的问题

### 问题 1：无法点击 Google 按钮

**原因**：环境变量未正确配置

**解决**：
```bash
# 检查 .env 文件中是否有：
VITE_GOOGLE_CLIENT_ID=249907665019-71e2lkp4m8l9tf7cd6o45fuj2v08tash.apps.googleusercontent.com
```

### 问题 2：授权后显示错误

**原因**：可能是重定向 URI 不匹配

**解决**：
1. 检查浏览器 URL 是否正确（`http://localhost:5173`）
2. 查看浏览器控制台错误信息
3. 重启开发服务器

### 问题 3：无法创建新账户

**原因**：邮箱已存在

**解决**：
- 使用不同的 Google 账户
- 或关联现有账户

## 技术细节（可选阅读）

### 安全机制

使用 **PKCE** (Proof Key for Code Exchange) 确保安全：
- 生成随机的 `code_verifier`
- 计算 `code_challenge`
- 服务器验证 token 时验证这些参数
- 防止授权码被拦截

### 数据流

```
浏览器 → Google → 浏览器 → 你的服务器 → 数据库
  ↓        ↓        ↓           ↓          ↓
登录    授权    回调    交换token   创建账户
```
